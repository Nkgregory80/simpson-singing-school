Cookie policy

This website uses privacy-friendly web analytics to understand how visitors use the site.

Last updated: 11 August 2026

What cookies are

Cookies are small text files stored on a device by a website. They can be used for essential functions, preferences, audience measurement, advertising or tracking. Similar technologies include local storage, tracking pixels and device identifiers.

Cookies and technologies used by this website

Vercel Web Analytics

This website uses Vercel Web Analytics, a privacy-friendly analytics service that collects anonymous aggregated usage data to help us understand how the site is used and improve the visitor experience.

Privacy-friendly approach: Vercel Web Analytics does not use traditional cookies, does not track visitors across websites, does not collect personal information, and does not require consent under GDPR and similar privacy laws. The service uses beacons (small requests to the server) to count page views in an anonymous, aggregated way.

No visitor identifiers, IP addresses, or personal information are stored. Data is retained in aggregate form only and cannot be used to identify individual visitors.

Other technologies

Simpson Singing School does not use advertising pixels, social media tracking plugins, or embedded third-party media that would track visitors.

The enquiry form

The enquiry form prepares an email in your own email application. The website does not send the form to a website database and does not use cookies or browser storage to retain the form contents.

If you choose “Copy enquiry”, your browser’s clipboard feature is used only at that moment to copy the message you prepared.

Hosting logs

Like most websites, the hosting provider may automatically process technical request information such as an IP address, browser type, requested page, date and time for security and service operation. These server logs are not cookies and are controlled by the hosting provider.

See the Privacy Notice for more information about how personal information is handled.

Browser controls

Because Vercel Web Analytics is privacy-friendly and cookieless, it should work with most browser privacy settings. If you use a content blocker or disable JavaScript entirely, analytics beacons may be blocked, but this will not affect the website's functionality.

Future changes

If additional analytics, embedded services or tracking technologies are introduced that require consent, this policy will be updated and those technologies will not be activated until the visitor has made an appropriate choice.
