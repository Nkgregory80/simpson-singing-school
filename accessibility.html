Access for everyone

Accessibility statement

Simpson Singing School wants this website and its information to be usable by as many people as possible.

Prepared: 4 August 2026

Our accessibility aim

The aim is to meet the Web Content Accessibility Guidelines version 2.2 at level AA where reasonably possible. The website is designed to work on phones, tablets and desktop computers and with current assistive technologies.

What you should be able to do

  • Zoom the page and reflow content without horizontal scrolling at common mobile widths.
  • Navigate using a keyboard and see a visible focus indicator.
  • Skip directly to the main content.
  • Use headings, landmarks, labels and link text that describe their purpose.
  • Read text with sufficient colour contrast and without relying on colour alone.
  • Reduce non-essential motion using your device’s reduced-motion setting.

Known limitations

The video in the gallery does not currently include captions or a full transcript. Please contact Morag for a written description or transcript. Some older browsers may not support every visual effect, but the content and essential functions should remain available.

If you find another problem, please report it so it can be investigated and corrected where reasonably possible.

Requesting information in another format

If you need information in a different format, such as larger text, plain text or information explained by telephone, email Simpsonmorag@gmail.com or call 07818 464546. Please explain the format you need and how best to contact you.

Reporting an accessibility problem

Contact Morag using the details above and include the page address, a description of the problem, the device or browser used, and any assistive technology involved. A response will normally be provided within 10 working days.

Enforcement

If you are not satisfied with the response, the Equality Advisory Support Service provides advice about rights under the Equality Act 2010.

How this statement was prepared

This statement was prepared through a self-assessment of the website’s structure, keyboard operation, responsive layout, text alternatives, labels and colour contrast. It will be reviewed when the website changes or when an accessibility issue is reported.
